# 🎬 Watch List

Мой список аниме, фильмов, сериалов и манги: где остановился и что поставил после просмотра.

**Сайт:** https://dstratonov1234.github.io/watch-list/

## Как это устроено

- `data/titles.json` — все тайтлы: из каких частей состоят (сезоны, тома, фильмы) и сколько в них серий
- `data/episodes/` — названия и кадры серий
- `data/quiz/` — опросники: у каждого тайтла свой, написанный под него; по ответам ставится оценка от 0 до 10
- `index.html` + `assets/` — статический сайт на GitHub Pages, без сборки
- `themes/<тайтл>/` — уникальное оформление тайтла: стили, модуль с интерактивом и эффектами, сгенерированные ассеты
- ветка `state`, файл `progress.json` — мои отметки и ответы: сайт пишет их туда сам через GitHub API (токен хранится только в моём браузере)
- `scripts/` — проверка данных, отметки, генерация ассетов, скриншоты в headless Chrome

Отмечаю серии и прохожу опросники я сам на сайте; тайтлы, опросники и оформление добавляет Claude по моим сообщениям — правила в [CLAUDE.md](CLAUDE.md). Движок общий с [Completionist List](https://dstratonov1234.github.io/completionist-list/).
